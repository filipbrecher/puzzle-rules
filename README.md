# puzzle-rules

Repo for storing puzzle genre and variant rules.

### Info

I tried to make a simple way to organize the variants for personal use, but I will share it publicly as well.
Genre + Variant combinations can be seen in appearances with possible links to sites where they appeared. There may be appearances with multiple Genres or Variants.
A lot of inspiration comes from Puzsq and personal experience with solving variant (and non-variant) puzzles.

I wanted to make a quick first page with AI to see if this way of organizing would work.

### Language support

It supports English, Japanese and Czech for now, but it's easy to add a new language. English ... obviously. Japanese because I will use most of the rules from Puzsq so I want to include their original Japanese versions as well. Czech because I want to record Czech versions for easier use in future Czech tournaments (previously when making a tournament I either wrote the rules again or searched on different Czech websites / looked through past Czech tournament papers or through older latex files with those Genres).

### Usage

Go to https://filipbrecher.github.io/puzzle-rules where it's accessible for viewing and browsing.
